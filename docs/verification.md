## 仓库脚本与文档验证

本次在隔离目录中重新运行了 4 项自动验证，全部通过：

1. 根 CA 自签名与服务端证书签名、CA/叶子约束、RSA 3072 位密钥配对、服务端用途、多个 SAN 和证书有效期正确。
2. 重复执行生成器会拒绝覆盖已有材料，并验证所有文件摘要未变化。
3. 无效 IP 会在写文件前失败，不留下半套证书。
4. 使用新生成证书、随机测试凭据、独立数据目录和随机本机端口启动一份临时 MinIO；完成 HTTPS 健康/控制台检查、S3 建桶/列举/写读、重启后的字节一致性检查，并删除测试对象和桶。

第 4 项仅复制已验证的本机 MinIO 二进制到隔离目录，没有重新编译上游项目，没有导入真实凭据，没有修改 Windows 根证书库，也没有重启实际运行的 MinIO。测试曾发现“API 就绪早于控制台就绪”的等待竞态，已改为等待两者都返回 200 后再检查，重新运行通过。

另外解析了 **8 个部署 PowerShell 脚本**和手动教程中的 **19 个 PowerShell 命令块**，没有语法错误。集成测试还调用了 `examples/create_bucket.py` 中的 SDK 建桶方法，确认新桶可以创建，重复调用不会覆盖已有桶。语法检查不等于所有系统管理命令在另一台电脑上都已实跑；计划任务、证书导入、交互凭据输入和网络策略仍取决于使用者环境。

Markdown 内部引用及 PNG 文件由 `tools/check_docs.py` 检查，发布内容扫描排除了私钥块、GitHub 令牌和不应打包的运行文件。手动核对了仓库不会包含本机密码、实际网络地址和正在使用的隧道域名。
